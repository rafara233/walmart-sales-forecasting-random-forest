# Sales Forecasting Using the Random Forest Algorithm
This project predicts weekly Walmart sales using the Random Forest regression algorithm and compares multiple training-testing data split ratios (90:10, 80:20, 70:30, and 60:40) to evaluate model performance.

## Dataset
This project uses the **Walmart Sales Dataset** from Kaggle. The dataset contains weekly sales records from Walmart stores along with several economic and environmental factors that may influence sales performance. It includes **6,435 records** and **8 attributes**. :contentReference[oaicite:1]{index=1}

### Features
- **Store** – Store number
- **Date** – Sales week start date
- **Weekly_Sales** – Weekly sales (target variable)
- **Holiday_Flag** – Indicates whether the week includes a holiday
- **Temperature** – Air temperature in the region
- **Fuel_Price** – Regional fuel price
- **CPI** – Consumer Price Index
- **Unemployment** – Regional unemployment rate
